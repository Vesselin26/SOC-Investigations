# SOC Investigations Portfolio

## Overview

This repository contains hands-on cybersecurity investigations focused on phishing analysis, SIEM detections, endpoint compromise, command-and-control activity, and incident response scenarios.

The goal of this portfolio is to demonstrate practical skills in threat detection, log analysis, IOC investigation, attack chain reconstruction, and security reporting through realistic case-based investigations.
